# Flow Command for Mac

Say **“Flow Command, activate”** (or hold any key you choose), then tell your Mac what to do — it opens apps and websites, clicks, types and navigates for you.

- Simple commands (open apps and sites, search, type, shortcuts) run instantly on your Mac.
- Multi-step tasks use Claude (needs an Anthropic API key) — or turn on **Private mode** to keep everything on your Mac.
- Safety: asks before sending, paying, deleting or posting; hands passwords/codes/captchas to you; say “stop” or press **Esc** anytime.

## Install or update (one line, no "Open Anyway")
Open **Terminal**, paste this and press Enter:

```
curl -fsSL https://raw.githubusercontent.com/Itzsharad/flow-command/main/install.sh | bash
```

It downloads the latest version into Applications and opens it. Run the same line any time to update — your settings and permissions are kept.

## Free AI brain
Simple commands and chains run on your Mac for free. For tasks that need to look at the screen, add a free Google AI key: Settings → AI brain → follow the 3 steps (aistudio.google.com/apikey).
